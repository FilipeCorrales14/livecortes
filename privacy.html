1. Quem somos

LiveCortes é um programa gratuito para Windows que roda no computador do próprio usuário. Não existe servidor do LiveCortes: o desenvolvedor não recebe, não armazena e não vende dados dos usuários.

2. Dados que o app usa

  • Gravações e cortes: os vídeos das suas lives ficam na pasta que você escolhe no seu computador.
  • Tokens de acesso: ao conectar YouTube, Instagram ou TikTok, os tokens de autorização são salvos apenas no seu computador, na pasta de configuração do LiveCortes.
  • Dados da conta TikTok: com a permissão user.info.basic o app lê o seu open ID, nome de exibição e foto de perfil, apenas para mostrar qual conta está conectada. Com video.publish / video.upload o app envia os vídeos que você confirmou.
  • Chat da live: mensagens públicas do chat (Twitch, Kick, YouTube) são lidas apenas para ajudar a identificar os melhores momentos.

3. Serviços de terceiros

Os dados só são enviados aos serviços que você mesmo configura: YouTube (Google), Instagram (Meta), TikTok e o provedor de IA escolhido (Groq ou OpenAI), que recebe o áudio e a transcrição para escolher os cortes. Cada serviço segue a própria política de privacidade.

4. Compartilhamento

O LiveCortes não compartilha nem vende dados para ninguém. Nenhum vídeo é publicado sem a confirmação do usuário.

5. Exclusão dos dados

Você pode desconectar qualquer conta nas configurações do app, revogar o acesso nas configurações do TikTok, Google ou Meta, e apagar a pasta de configuração e os vídeos do seu computador. Como não há servidor, nenhum dado fica guardado pelo desenvolvedor.

6. Contato

Dúvidas ou pedidos: abra uma issue em github.com/FilipeCorrales14/livecortes/issues.

English summary

LiveCortes is a free Windows desktop app that runs entirely on the user's own computer. There is no LiveCortes server; the developer does not collect, store or sell user data.

  • Recordings and clips stay in a folder the user chooses on their computer.
  • Access tokens for YouTube, Instagram and TikTok are stored only locally.
  • TikTok data: with user.info.basic the app reads the open ID, display name and avatar to show which account is connected; with video.publish/video.upload it uploads only the videos the user has reviewed and confirmed.
  • Data is sent only to services the user configures (YouTube, Instagram, TikTok and the chosen AI provider, Groq or OpenAI, for transcription and clip selection).
  • Users can disconnect accounts in the app, revoke access in their TikTok/Google/Meta settings, and delete the local config folder and videos at any time.
  • Contact: GitHub issues.
