# LiveCortes

Programa gratuito para Windows que trabalha com o OBS Studio: divide a gravação das lives em blocos, encontra os melhores momentos, gera cortes verticais com legenda e publica nas suas próprias contas do YouTube, Instagram e TikTok, com prévia e confirmação antes de cada post.

Free Windows app for streamers that works with OBS Studio: splits stream recordings, finds the best moments, renders captioned vertical clips and publishes them to your own YouTube, Instagram and TikTok accounts, with a preview and confirmation before each post.
